Usage Flow:
===========

1. Import controller:
   import { fpsBatchController } from '@/services/fps';

2. Start monitoring:
   fpsBatchController.start();

3. Add UI:
   <BatchControlPanel controller={fpsBatchController} />

4. Listen to batch changes:
   controller.getBatchManager().onBatchChange(event => {
     // Update Three.js scene
   });

Component Batches (Priority Order):
====================================

0. COURTS_ONLY     (0 FPS)   - Always enabled
1. BUILDINGS       (5 FPS)   - Structures
2. GRASS          (10 FPS)   - Ground cover
3. TREES           (8 FPS)   - Foliage
4. SHADOWS        (12 FPS)   - Dynamic shadows
5. WEATHER         (7 FPS)   - Atmosphere
6. PARTICLES      (15 FPS)   - Effects
7. POST_PROCESSING (10 FPS)  - Post-FX
8. REFLECTIONS    (18 FPS)   - Advanced lighting

FPS Thresholds:
===============

CRITICAL: < 25 FPS → Emergency mode (courts only)
LOW:      < 40 FPS → Downgrade batches
STABLE:   >= 55 FPS → Upgrade batches

Stability Requirements:
=======================

Downgrade: 3 consecutive samples below threshold
Upgrade:   6 consecutive samples above threshold
Interval:  1 second between checks
